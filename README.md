# 摸物品 · 开箱寻宝（C# WinForms）

GitHub 仓库：https://github.com/sss2443/sixsenven
当前版本：v1.1

按草图里的玩法做的桌面小游戏：棋盘上每一格都摆着一件物品的**阴影**，玩家用鼠标左键按住不放，放大镜会在阴影上来回扫，镜片外圈的光圈转满一圈，这件物品就算搜到手，收进背包，之后可以卖钱。

## 目录

- `LootSearch.csproj` —— .NET 8 WinForms 工程
- `Program.cs` —— 程序入口（启动开始页面）
- `Core/GameData.cs` —— 物品、稀有度、箱子档位、地图、宠物、棋盘生成、引擎、存档（纯逻辑，不含界面代码）
- `UI/Theme.cs` —— 配色和字体
- `UI/ItemArt.cs` —— 十一种物品的矢量造型（阴影态 / 搜出态）
- `UI/PetArt.cs` —— 狗 / 猫 / 龙的矢量造型
- `UI/BoardPanel.cs` —— 棋盘控件：格子、阴影、放大镜、光圈进度、自动搜索
- `UI/HallForm.cs` —— 开始页面：开始游戏 / 更新日志 / 设置
- `UI/MainForm.cs` —— 主游戏窗口：资金、地图、箱子按钮、宠物入口、背包、出售
- `UI/AdminForm.cs` —— 管理员模式：发钱、生成任意物品
- `UI/PetsForm.cs` —— 宠物界面：孵蛋、宠物列表、最多 3 只出战
- `UI/SettingsForm.cs` —— 设置：自动搜索、自动出售、管理员模式
- `UI/ChangelogForm.cs` —— 更新日志
- `app.ico` —— 程序图标（二进制，GitHub 仓库未收录；csproj 已做 Exists 判断，缺图标也能正常编译）

## 玩法

1. **开始页面**：点「开始游戏」进入游戏，「更新日志」看版本改动，「设置」调开关。
2. **选地图**：零号大坝默认可用；长弓西谷要花 ¥90,000 解锁，整体出货概率更高。
3. **选箱子**：灰色免费，绿 ¥1,000，蓝 ¥5,000，紫 ¥10,000，红 ¥30,000。开箱当场扣入场费。
4. **搜物品**：按住左键停在阴影上，镜片外的光圈会转满一圈；中途移开格子进度会回退。开了「自动搜索」后点一下就直接搜出。
5. **出售**：右侧背包里选中一件点「出售选中」，或者「全部出售」/双击物品。开了「自动出售」则搜到即卖。
6. 24 格里有一部分是空格，箱子越好，物品越少但单价越高。

## 地图

| 地图 | 解锁 | 出货倾向 | 物品价值 |
|---|---|---|---|
| 零号大坝 | 默认 | 普通 44.8% / 精良 33.8% / 史诗 16.6% / 传说 4.7% | ×1.00 |
| 长弓西谷 | ¥90,000 | 普通 27.8% / 精良 38.8% / 史诗 25.8% / 传说 7.6% | ×1.15 |

（上面的概率是蓝箱 300 次开箱的实测分布，权重在 `MapDefinition.All` 的 `RarityFactors` 里。）

## 箱子配置

| 箱子 | 入场费 | 物品数 | 单价区间 | 单件搜索耗时 |
|---|---|---|---|---|
| 灰箱 | 免费 | 14 | ¥25 – ¥110 | 0.9 秒 |
| 绿箱 | 1,000 | 13 | ¥45 – ¥120 | 1.1 秒 |
| 蓝箱 | 5,000 | 11 | ¥280 – ¥620 | 1.4 秒 |
| 紫箱 | 10,000 | 10 | ¥620 – ¥1,300 | 1.7 秒 |
| 红箱 | 30,000 | 9 | ¥1,700 – ¥3,700 | 2.1 秒 |

稀有度（普通 / 精良 / 史诗 / 传说）在单价上再乘 1.0 / 1.25 / 1.7 / 2.4，箱子越贵，出稀有货的概率越高。

## 宠物

宠物蛋 ¥10,000 一颗，孵化概率与加成：

| 宠物 | 出货率 | 物品价值加成 | 搜索速度加成 |
|---|---|---|---|
| 狗 | 65% | +5% | +5% |
| 猫 | 30% | +12% | +12% |
| 龙 | 5% | +30% | +25% |

- 同一只宠物可以重复孵出来，每只单独计数、有自己的名字。
- 最多同时出战 3 只，加成叠加（例如 3 条龙 = 价值 ×1.9、搜索速度 +75%）。
- 价值加成在**开新箱子**时结算进物品价格；搜索速度加成实时生效，对当前棋盘也有效。

## 管理员模式

在设置里把「管理员模式」打开，主界面右上角出现「管理员」按钮：

- 「给我 ¥999,999」一键发放。
- 自选造型 / 品质 / 价值，生成任意物品直接放进背包，出售规则和正常物品一样。

## 设置

- **自动搜索**：点一下阴影直接搜出，不用按住等光圈转完。
- **自动出售**：搜到的物品当场按价值卖成现金。
- **管理员模式**：解锁上面那套后台功能。

## 存档

- 自动存档：每搜到一件、每卖掉一次、每次开箱、每次孵蛋/解锁地图都会写盘；关窗口时再存一次。
- 手动存档：右上角「保存进度」。
- 存档文件 `save.json` 默认放在 exe 同目录（和 exe 一起拷走就能带走进度）；目录没有写入权限时自动退到 `%LOCALAPPDATA%\LootSearch\save.json`。
- 记录内容：资金、背包、当前地图与解锁状态、箱子格子状态、宠物列表与出战状态、设置开关、已搜/已售数量、累计支出和收入。
- 旧版（v1.0）存档可以直接读，新字段自动补默认值。
- 「重开存档」会清空进度，资金重置为 ¥1,200，地图和宠物一起重置。

## 编译

需要 .NET 8 SDK（Windows 上直接双击 `build.bat` 即可）。

```bat
dotnet publish -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
  -p:EnableCompressionInSingleFile=true -o publish
```

输出 `publish\LootSearch.exe`，单文件、自带运行时，64 位 Windows 10/11 直接双击运行，不用装 .NET。
