# 摸物品 · 开箱寻宝（C# WinForms）

按草图里的玩法做的桌面小游戏：棋盘上每一格都摆着一件物品的**阴影**，玩家用鼠标左键按住不放，放大镜会在阴影上来扫，镜片外圈的光圈转满一圈，这件物品就算搜到手，收进背包，之后可以卖钱。

## 目录

- `LootSearch.csproj` —— .NET 8 WinForms 工程
- `Program.cs` —— 程序入口
- `Core/GameData.cs` —— 物品、箱子档位、棋盘生成、引擎、存档（纯逻辑，不含任何界面代码）
- `UI/Theme.cs` —— 配色和字体
- `UI/ItemArt.cs` —— 十一种物品的矢量造型（阴影态 / 搜出态）
- `UI/BoardPanel.cs` —— 棋盘控件：格子、阴影、放大镜、光圈进度
- `UI/MainForm.cs` —— 主窗口：资金、箱子按钮、背包、出售
- `app.ico` —— 程序图标

## 玩法

1. **选箱子**：灰色免费，绿 ¥1,000，蓝 ¥5,000，紫 ¥10,000，红 ¥30,000。开箱当场扣入场费。
2. **搜物品**：按住左键停在阴影上，镜片外的光圈会转满一圈；中途移开格子进度会回退。
3. **出售**：右侧背包里选中一件点「出售选中」，或者「全部出售」/双击物品。
4. 24 格里有一部分是空格，箱子越好，物品越少但单价越高。

## 箱子配置

| 箱子 | 入场费 | 物品数 | 单价区间 | 单件搜索耗时 |
|---|---|---|---|---|
| 灰箱 | 免费 | 14 | ¥25 – ¥110 | 0.9 秒 |
| 绿箱 | 1,000 | 13 | ¥45 – ¥120 | 1.1 秒 |
| 蓝箱 | 5,000 | 11 | ¥280 – ¥620 | 1.4 秒 |
| 紫箱 | 10,000 | 10 | ¥620 – ¥1,300 | 1.7 秒 |
| 红箱 | 30,000 | 9 | ¥1,700 – ¥3,700 | 2.1 秒 |

稀有度（普通 / 精良 / 史诗 / 传说）在单价上再乘 1.0 / 1.25 / 1.7 / 2.4，箱子越贵，出稀有货的概率越高。所有数值都在 `Core/GameData.cs` 的 `BoxTierDefinition.All` 里，直接改就行。

## 存档

- 自动存档：每搜到一件、每卖掉一次、每次开箱都会写盘；关窗口时再存一次。
- 手动存档：右上角「保存进度」。
- 存档文件 `save.json` 默认放在 exe 同目录（和 exe 一起拷走就能带走进度）；目录没有写入权限时自动退到 `%LOCALAPPDATA%\LootSearch\save.json`。
- 记录内容：资金、背包、当前箱子的格子状态、已搜/已售数量、累计支出和收入。
- 「重开存档」会清空进度，资金重置为 ¥1,200。

## 编译

需要 .NET 8 SDK（Windows 上直接双击 `build.bat` 即可）。

```bat
dotnet publish -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
  -p:EnableCompressionInSingleFile=true -o publish
```

输出 `publish\LootSearch.exe`，单文件、自带运行时，64 位 Windows 10/11 直接双击运行，不用装 .NET。
